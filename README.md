# The Meal Planner
A modern recipe discovery app built with React. Search thousands of recipes by name or ingredient, save favorites, plan your week, and get a random dish when you can't decide.

## Features
-  **Search** recipes by name or by ingredient
-  **Surprise Me** — get a random recipe with one click
-  **Browse categories** — Beef, Chicken, Dessert, Seafood, and more
-  **Save favorites** — persisted in localStorage, survives refresh
-  **Weekly planner** — assign meals to any day of the week
-  **Responsive** — works on desktop, and mobile
-  **Polished UX** — loading skeletons, empty states, and toast notifications

## Technologies
| Layer | Technology |
|---|---|
| Framework | React |
| Routing | React Router |
| Styling | plain CSS with CSS variables |
| State | React Context (`Favorites`, `Feedback`) |
| Persistence | localStorage |
| Icons | Font Awesome |
| API | [TheMealDB](https://www.themealdb.com/api.php) |
| Deploy | Vercel |
